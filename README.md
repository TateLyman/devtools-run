# DevTools.run

14 free developer tools that run entirely in your browser. No sign-up, no tracking, no server calls.

**Live:** [devtools-site-delta.vercel.app](https://devtools-site-delta.vercel.app)

## Tools

- JSON Formatter & Validator
- Base64 Encoder / Decoder
- Hash Generator (MD5, SHA-1, SHA-256)
- JWT Decoder
- Unix Timestamp Converter
- SOL / USD Calculator
- Solana Token Lookup
- Solana Wallet Checker
- Token Safety Scanner
- Regex Tester
- Color Converter (HEX, RGB, HSL)
- Markdown Preview
- URL Encoder / Decoder
- And more...

## Stack

- Next.js 14 (App Router)
- Tailwind CSS
- Deployed on Vercel

## Run Locally

```bash
npm install
npm run dev
```
